# 樂理與樂器工具站

面向愛樂者的免費小站：練琴與樂理工具，以及多品牌樂器序號查詢與年份參考。

打開網站：[https://heiguozhi.wang/zh-Hant/](https://heiguozhi.wang/zh-Hant/)

另有 [English](./README.md) 與 [简体中文](./README.zh-Hans.md) 說明。網站本身也提供簡體、英文、繁體三種介面。

## 工具

- [調音器](https://heiguozhi.wang/zh-Hant/tools/tuner.html) — 用麥克風即時看音高，適合各類樂器。
- [節拍器](https://heiguozhi.wang/zh-Hant/tools/metronome.html) — 日常練習用的節拍工具，可帶語音提示。
- [五度圈](https://heiguozhi.wang/zh-Hant/tools/circle-of-fifths.html) — 一眼看清調性關係與常見和弦走向。
- [試音場](https://heiguozhi.wang/zh-Hant/tools/tone-playground.html) — 拼效果器、箱頭、箱體，線上試聽電吉他/電貝斯音色。
- [和弦字典](https://heiguozhi.wang/zh-Hant/tools/chord-dictionary.html) — 吉他與烏克麗麗指法、構成音，可試聽。
- [指板可視化](https://heiguozhi.wang/zh-Hant/tools/fretboard.html) — 在吉他、貝斯、烏克麗麗指板上查看音階與和弦。
- [音高頻率參考](https://heiguozhi.wang/zh-Hant/tools/pitch-frequency.html) — 可調 A4 的音名頻率表，可試聽。
- [音階探索器](https://heiguozhi.wang/zh-Hant/tools/scale-explorer.html) — 瀏覽 20+ 種音階，帶指板與試聽。
- [和弦進行建構器](https://heiguozhi.wang/zh-Hant/tools/progression-builder.html) — 按級數拼和弦進行，可調節 BPM 並播放。
- [鼓機](https://heiguozhi.wang/zh-Hant/tools/rhythm-patterns.html) — 多種風格節奏型，可調速度。
- [音程聽辨](https://heiguozhi.wang/zh-Hant/tools/ear-training.html) — 練耳朵，聽辨常見音程。
- [線規轉換器](https://heiguozhi.wang/zh-Hant/tools/wire-gauge-converter.html) — AWG、SWG、線徑與截面積互算，方便佈線選型。
