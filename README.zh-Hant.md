## 工具

- [調音器](https://heiguozhi.wang/zh-Hant/tools/tuner.html) — 透過麥克風即時偵測音高，適用於吉他、貝斯、小提琴等樂器。支援調整 A4 標準音。
- [節拍器](https://heiguozhi.wang/zh-Hant/tools/metronome.html) — 線上節拍器，支援拍號、拍速點選與可選語音提示，用於日常練習與節奏訓練。
- [五度圈](https://heiguozhi.wang/zh-Hant/tools/circle-of-fifths.html) — 可視化五度圈，涵蓋七種教會調式，用於理解調性五度關係、大小調相對關係與常見和弦進行。適合作曲、編曲與樂理學習。
- [試音場](https://heiguozhi.wang/zh-Hant/tools/tone-playground.html) — 電吉他 / 電貝斯訊號鏈沙箱：可組合效果器、箱頭、箱體與 DI，並對照乾濕波形。部分箱頭支援 NAM 取樣音色；亦可接入麥克風或上傳本機乾聲。屬教學向仿真，並非任何品牌的官方產品。
- [和弦字典](https://heiguozhi.wang/zh-Hant/tools/chord-dictionary.html) — 吉他與烏克麗麗和弦參考，涵蓋大三、小三、七和弦、掛留等類型，提供開放把位與可移動指法、SVG 指法圖、構成音與音訊試聽。
- [指板可視化](https://heiguozhi.wang/zh-Hant/tools/fretboard.html) — 互動式指板，支援吉他、貝斯與烏克麗麗的多種調弦、音階與和弦模板、自訂品位範圍及音訊預覽。
- [音高頻率參考](https://heiguozhi.wang/zh-Hant/tools/pitch-frequency.html) — 基於十二平均律的頻率表，A4 可在 392–470 Hz 間調節，列出 C0–C10 全部半音的理論頻率，並支援逐音試聽。
- [音階探索器](https://heiguozhi.wang/zh-Hant/tools/scale-explorer.html) — 收錄二十餘種音階類型（大調、小調、五聲、藍調、對稱與其集合等），附指板可視化與音訊。
- [和弦進行建構器](https://heiguozhi.wang/zh-Hant/tools/progression-builder.html) — 按級數編排和弦進行，支援自訂序列、常見預設、BPM 調節與音訊播放。
- [鼓機](https://heiguozhi.wang/zh-Hant/tools/rhythm-patterns.html) — 按風格分類的鼓機節奏型庫（搖滾、放克、森巴、雷鬼等），支援 BPM 調節與可視化播放。
- [音程聽辨](https://heiguozhi.wang/zh-Hant/tools/ear-training.html) — 音程識別訓練，提供多種音程集合與難度，支援上行、下行與和聲播放，並統計正確率。
- [線規轉換器](https://heiguozhi.wang/zh-Hant/tools/wire-gauge-converter.html) — 面向樂器與音訊佈線場景，在 AWG、SWG、公制/英制線徑與截面積之間換算。
