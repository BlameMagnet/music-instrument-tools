# Herramientas para músicos

Un sitio gratuito para músicos: utilidades de práctica y teoría, más consulta de números de serie y año de fabricación de varios instrumentos.

Abrir el sitio: [https://heiguozhi.wang/es/](https://heiguozhi.wang/es/)

## Herramientas

- [Afinador](https://heiguozhi.wang/es/tools/tuner.html) — Afina con el micrófono; sirve para muchos instrumentos.
- [Metrónomo](https://heiguozhi.wang/es/tools/metronome.html) — Clic claro para practicar, con cues de voz opcionales.
- [Círculo de quintas](https://heiguozhi.wang/es/tools/circle-of-fifths.html) — Ve cómo se relacionan las tonalidades y movimientos armónicos habituales.
- [Caja de tonos](https://heiguozhi.wang/es/tools/tone-playground.html) — Combina pedales, amplis y pantallas y prueba tonos de guitarra/bajo en línea.
- [Diccionario de acordes](https://heiguozhi.wang/es/tools/chord-dictionary.html) — Formas de guitarra y ukelele, notas y audio.
- [Diapasón](https://heiguozhi.wang/es/tools/fretboard.html) — Notas, escalas y acordes en guitarra, bajo o ukelele.
- [Frecuencias](https://heiguozhi.wang/es/tools/pitch-frequency.html) — Tabla de frecuencias con A4 ajustable y reproducción.
- [Explorador de escalas](https://heiguozhi.wang/es/tools/scale-explorer.html) — Más de 20 escalas en el diapasón con audio.
- [Progresiones](https://heiguozhi.wang/es/tools/progression-builder.html) — Arma y reproduce progresiones por grados.
- [Ritmos](https://heiguozhi.wang/es/tools/rhythm-patterns.html) — Patrones por estilo con control de BPM.
- [Entrenamiento auditivo](https://heiguozhi.wang/es/tools/ear-training.html) — Practica reconocer intervalos de oído.
- [Calibres](https://heiguozhi.wang/es/tools/wire-gauge-converter.html) — Convierte AWG, SWG, diámetro y sección para cableado de audio.

## Consulta de número de serie

Algunas marcas populares para empezar. Hay más en la [página de inicio](https://heiguozhi.wang/es/).

- [Gibson](https://heiguozhi.wang/es/sn-decoders/gibson.html)
- [Fender](https://heiguozhi.wang/es/sn-decoders/fender.html)
- [Epiphone](https://heiguozhi.wang/es/sn-decoders/epiphone.html)
- [Squier](https://heiguozhi.wang/es/sn-decoders/squier.html)
- [Ibanez](https://heiguozhi.wang/es/sn-decoders/ibanez.html)
- [PRS](https://heiguozhi.wang/es/sn-decoders/prs.html)
- [Martin](https://heiguozhi.wang/es/sn-decoders/martin.html)
- [Taylor](https://heiguozhi.wang/es/sn-decoders/taylor.html)
- [ESP / LTD](https://heiguozhi.wang/es/sn-decoders/esp-ltd.html)
- [Edwards / GrassRoots](https://heiguozhi.wang/es/sn-decoders/edwards-grassroots.html)

Las consultas sirven para estimar el año y datos relacionados; no son un certificado de autenticidad. La caja de tonos es un simulador didáctico, no un producto oficial de ninguna marca.
