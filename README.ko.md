# 음악·악기 도구

음악 애호가를 위한 무료 사이트: 연습·이론 도구와 여러 브랜드 악기 시리얼 넘버 조회 및 연도 참고.

사이트 열기: [https://heiguozhi.wang/ko/](https://heiguozhi.wang/ko/)

이 안내의 언어: [English](./README.md) · [简体中文](./README.zh-Hans.md) · [繁體中文](./README.zh-Hant.md) · [日本語](./README.ja.md) · [Español](./README.es.md) · [Tiếng Việt](./README.vi.md) · [Bahasa Indonesia](./README.id.md) · [Português (Brasil)](./README.pt-BR.md) · [ภาษาไทย](./README.th.md)

## 도구

- [튜너](https://heiguozhi.wang/ko/tools/tuner.html) — 마이크로 음고를 보며 조율.
- [메트로놈](https://heiguozhi.wang/ko/tools/metronome.html) — 연습용 클릭, 음성 큐 옵션.
- [5도권](https://heiguozhi.wang/ko/tools/circle-of-fifths.html) — 조의 관계와 흔한 화성 진행을 한눈에.
- [톤 체험](https://heiguozhi.wang/ko/tools/tone-playground.html) — 이펙터·앰프·캐비닛을 조합해 기타/베이스 톤을 온라인으로 들어보기.
- [코드 사전](https://heiguozhi.wang/ko/tools/chord-dictionary.html) — 기타·우쿨렐레 운지, 구성음, 미리 듣기.
- [지판](https://heiguozhi.wang/ko/tools/fretboard.html) — 기타·베이스·우쿨렐레 지판에서 음계와 코드 확인.
- [음고·주파수](https://heiguozhi.wang/ko/tools/pitch-frequency.html) — A4 조절 가능한 음이름 주파수표와 재생.
- [음계 탐색](https://heiguozhi.wang/ko/tools/scale-explorer.html) — 20여 가지 음계를 지판과 소리로.
- [코드 진행](https://heiguozhi.wang/ko/tools/progression-builder.html) — 도수로 진행을 만들고 재생.
- [드럼 머신](https://heiguozhi.wang/ko/tools/rhythm-patterns.html) — 스타일별 패턴과 BPM.
- [음정 훈련](https://heiguozhi.wang/ko/tools/ear-training.html) — 음정을 귀로 구분하는 연습.
- [와이어 게이지](https://heiguozhi.wang/ko/tools/wire-gauge-converter.html) — AWG / SWG / 직경 / 단면적 환산(오디오 배선용).

## 시리얼 넘버 조회

자주 찾는 브랜드부터. 더 많은 브랜드는 [홈](https://heiguozhi.wang/ko/)에서.

- [Gibson](https://heiguozhi.wang/ko/sn-decoders/gibson.html)
- [Fender](https://heiguozhi.wang/ko/sn-decoders/fender.html)
- [Epiphone](https://heiguozhi.wang/ko/sn-decoders/epiphone.html)
- [Squier](https://heiguozhi.wang/ko/sn-decoders/squier.html)
- [Ibanez](https://heiguozhi.wang/ko/sn-decoders/ibanez.html)
- [PRS](https://heiguozhi.wang/ko/sn-decoders/prs.html)
- [Martin](https://heiguozhi.wang/ko/sn-decoders/martin.html)
- [Taylor](https://heiguozhi.wang/ko/sn-decoders/taylor.html)
- [ESP / LTD](https://heiguozhi.wang/ko/sn-decoders/esp-ltd.html)
- [Edwards / GrassRoots](https://heiguozhi.wang/ko/sn-decoders/edwards-grassroots.html)

조회 결과는 연도 등의 참고용이며 진위 증명이 아닙니다. 톤 체험은 교육용 시뮬레이터이며 각 브랜드 공식 제품이 아닙니다.
