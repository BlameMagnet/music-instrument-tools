# 음악·악기 도구

연습·이론 학습 및 다브랜드 악기 시리얼 넘버 연도 참조를 위한 온라인 도구 사이트입니다.

사이트: [https://heiguozhi.wang/ko/](https://heiguozhi.wang/ko/)

다른 언어: [English](./README.md) · [简体中文](./README.zh-Hans.md) · [繁體中文](./README.zh-Hant.md) · [日本語](./README.ja.md) · [Español](./README.es.md) · [Tiếng Việt](./README.vi.md) · [Bahasa Indonesia](./README.id.md) · [Português (Brasil)](./README.pt-BR.md) · [ภาษาไทย](./README.th.md)

## 도구

- [튜너](https://heiguozhi.wang/ko/tools/tuner.html) — 마이크로 음고를 실시간 감지합니다. 기타, 베이스, 바이올린 등에 대응하며 A4 참조음을 조절할 수 있습니다.
- [메트로놈](https://heiguozhi.wang/ko/tools/metronome.html) — 박자, 탭 템포, 선택적 음성 큐를 지원하는 온라인 메트로놈입니다. 일상 연습과 리듬 훈련에 사용합니다.
- [5도권](https://heiguozhi.wang/ko/tools/circle-of-fifths.html) — 일곱 가지 교회 선법을 포함하는 인터랙티브 5도권입니다. 조 간 5도 관계, 장·단조의 나란한 관계, 정형 화성 진행 이해에 쓰이며 작곡·편곡·이론 학습에 적합합니다.
- [톤 체험](https://heiguozhi.wang/ko/tools/tone-playground.html) — 일렉 기타/베이스 시그널 체인 샌드박스입니다. 이펙터, 앰프 헤드, 캐비닛, DI를 구성하고 드라이/웨트 파형을 비교할 수 있습니다. 일부 헤드는 NAM 샘플링 톤을 지원하며, 마이크 입력 또는 로컬 드라이 음원 업로드도 가능합니다. 교육용 시뮬레이션이며 어떤 브랜드의 공식 제품도 아닙니다.
- [코드 사전](https://heiguozhi.wang/ko/tools/chord-dictionary.html) — 기타·우쿨렐레 코드 참고입니다. 메이저, 마이너, 세븐스, 서스펜디드 등을 다루며 오픈/무버블 핑거링, SVG 다이어그램, 구성음, 오디오 미리듣기를 제공합니다.
- [지판](https://heiguozhi.wang/ko/tools/fretboard.html) — 기타, 베이스, 우쿨렐레용 인터랙티브 지판입니다. 다양한 튜닝, 음계·코드 템플릿, 프렛 범위 지정, 오디오 미리듣기를 지원합니다.
- [음고·주파수](https://heiguozhi.wang/ko/tools/pitch-frequency.html) — 12 평균율 기반 주파수표입니다. A4(392–470 Hz)를 조절할 수 있고 C0–C10의 모든 반음 이론 주파수를 나열하며 음명별 미리듣기를 지원합니다.
- [음계 탐색](https://heiguozhi.wang/ko/tools/scale-explorer.html) — 메이저, 마이너, 펜타토닉, 블루스, 대칭 음계 등 20종 이상의 음계를 수록하며 지판 시각화와 오디오를 제공합니다.
- [코드 진행](https://heiguozhi.wang/ko/tools/progression-builder.html) — 디그리(도수)로 코드 진행을 구성합니다. 사용자 정의 시퀀스, 정형 프리셋, BPM 조절, 오디오 재생을 지원합니다.
- [드럼 머신](https://heiguozhi.wang/ko/tools/rhythm-patterns.html) — 록, 펑크, 삼바, 레게 등 스타일별 드럼 패턴 라이브러리입니다. BPM 조절과 비주얼 재생을 지원합니다.
- [음정 훈련](https://heiguozhi.wang/ko/tools/ear-training.html) — 음정 인식 훈련입니다. 여러 음정 집합과 난이도, 상행/하행/화성 제시, 정답률 기록을 지원합니다.
- [와이어 게이지](https://heiguozhi.wang/ko/tools/wire-gauge-converter.html) — 악기 및 오디오 배선용으로 AWG, SWG, 미터법/야드파운드법 선경과 단면적을 환산합니다.

## 시리얼 넘버 조회

우선순위가 높은 브랜드 발췌(사이트 프리셋 순서). 기타 브랜드는 [홈](https://heiguozhi.wang/ko/) 또는 `/sn-decoders/{brand}.html`을 참조하십시오.

- [Gibson](https://heiguozhi.wang/ko/sn-decoders/gibson.html)
- [Fender](https://heiguozhi.wang/ko/sn-decoders/fender.html)
- [Epiphone](https://heiguozhi.wang/ko/sn-decoders/epiphone.html)
- [Squier](https://heiguozhi.wang/ko/sn-decoders/squier.html)
- [Ibanez](https://heiguozhi.wang/ko/sn-decoders/ibanez.html)
- [PRS](https://heiguozhi.wang/ko/sn-decoders/prs.html)
- [Martin](https://heiguozhi.wang/ko/sn-decoders/martin.html)
- [Taylor](https://heiguozhi.wang/ko/sn-decoders/taylor.html)
- [ESP / LTD](https://heiguozhi.wang/ko/sn-decoders/esp-ltd.html)
- [Edwards / GrassRoots](https://heiguozhi.wang/ko/sn-decoders/edwards-grassroots.html)

결과는 생산 연도 및 관련 속성의 추정치이며, 진위 증명이나 감정을 구성하지 않습니다.
