# 音楽・楽器ツール

練習・楽理学習、および多ブランド機材のシリアル番号・部品日付コード検索向けのオンラインツールサイトです。

サイト：[https://heiguozhi.wang/ja/](https://heiguozhi.wang/ja/)

## ツール

- [チューナー](https://heiguozhi.wang/ja/tools/tuner.html) — マイクによるリアルタイム音高検出。ギター、ベース、バイオリン等に対応し、サイト共通の A4 基準音（392–470 Hz）を調整できます。
- [メトロノーム](https://heiguozhi.wang/ja/tools/metronome.html) — 拍子・タップテンポ・任意の音声キューに対応したオンラインメトロノーム。日常練習およびリズム訓練向けで、ページ内に腕時計・小型画面・旧ブラウザ向けの軽量版リンクも備えます。
- [五度圏](https://heiguozhi.wang/ja/tools/circle-of-fifths.html) — 七種の教会モードを含む対話型五度圏。調同士の五度関係、長短調の相対関係、定番の和声進行の理解に用い、作曲・編曲・楽理学習に適します。
- [トーン試聴](https://heiguozhi.wang/ja/tools/tone-playground.html) — エレキギター／ベースの信号チェーン用サンドボックス。エフェクター、アンプヘッド、キャビネット IR、DI を組み合わせ、A/B 比較、チェーンバイパス、ドライ／ウェット波形比較、URL によるリグ共有に対応します。一部ヘッドは NAM サンプリング音色に対応し、マイク入力またはローカルのドライ音源アップロードも可能です。教材向けのシミュレーションであり、各ブランドの公式製品ではありません。
- [コード辞書](https://heiguozhi.wang/ja/tools/chord-dictionary.html) — ギター／ウクレレ向けコードリファレンス。メジャー、マイナー、セブンス、サス等に対応し、オープン／ムーバブルフィンガリング、SVG ダイアグラム、構成音、音声試聴を提供します。
- [指板表示](https://heiguozhi.wang/ja/tools/fretboard.html) — ギター、ベース、ウクレレ、マンドリン、バンジョーに加え、柳琴・琵琶・中阮・大阮・月琴などに対応した対話型指板。各種チューニング、スケール／コードテンプレート、12 フレット学習窓／全フレット切替、音声プレビューに対応します。
- [音高・周波数](https://heiguozhi.wang/ja/tools/pitch-frequency.html) — 十二平均律に基づく周波数表。A4（392–470 Hz）を調整でき、C0–C10 の全半音の理論周波数を一覧化し、音名ごとの試聴が可能です。
- [スケール探索](https://heiguozhi.wang/ja/tools/scale-explorer.html) — メジャー、マイナー、ペンタトニック、ブルース、対称音階、エキゾチック音階等を含む 20 種超のスケールを収録。多楽器対応の指板可視化（12 フレット／全フレット）と音声を備えます。
- [コード進行](https://heiguozhi.wang/ja/tools/progression-builder.html) — ディグリー（度数）に基づくコード進行の構築。任意シーケンス、定番プリセット、BPM 調整、音声再生に対応します。
- [ドラムマシン](https://heiguozhi.wang/ja/tools/rhythm-patterns.html) — ロック、ファンク、サンバ、レゲエ等のスタイル別パターンライブラリ。BPM 調整とビジュアル再生に対応します。
- [音程聴音](https://heiguozhi.wang/ja/tools/ear-training.html) — 音程識別トレーニング。複数の音程集合と難易度、上行／下行／ハーモニー提示、正答率の記録に対応します。
- [線径換算](https://heiguozhi.wang/ja/tools/wire-gauge-converter.html) — 楽器およびオーディオ配線向けに、AWG、SWG、メートル法／ヤード・ポンド法の線径と断面積を換算します。

### 部品日付コード

- [Celestion](https://heiguozhi.wang/ja/sn-decoders/celestion.html) — ギタースピーカー工場別日付コード検索と製造年リファレンス（EIA 方式ではありません）。
- [ポット日付コード](https://heiguozhi.wang/ja/sn-decoders/pot.html) — エレキギター／ベース用ポットの米国 EIA ソース日付コード検索（メーカーおよび製造年・週）。
- [スピーカー EIA 日付コード](https://heiguozhi.wang/ja/sn-decoders/speaker-eia.html) — ギターアンプ用スピーカー（Jensen、Rola、Oxford、Utah、Eminence 等）の米国 EIA ソース日付コード検索。
- [トランス EIA 日付コード](https://heiguozhi.wang/ja/sn-decoders/transformer-eia.html) — ヴィンテージ・ギターアンプ用トランスおよびチョーク（Schumacher、Triad、Stancor 等）の米国 EIA ソース日付コード検索。

結果は製造年および関連属性の推定であり（部品の日付は本体製造日の下限にすぎません）、真贋証明や鑑定を構成するものではありません。
