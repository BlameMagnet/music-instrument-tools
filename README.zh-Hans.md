# 乐理与乐器工具站

面向爱乐者的免费小站：练琴与乐理工具，以及多品牌乐器序列号查询与年份参考。

打开网站：[https://heiguozhi.wang](https://heiguozhi.wang)

另有 [English](./README.md) 与 [繁體中文](./README.zh-Hant.md) 说明。网站本身也提供简体、英文、繁体三种界面。

## 工具

- [调音器](https://heiguozhi.wang/tools/tuner.html) — 用麦克风实时看音高，适合各类乐器。
- [节拍器](https://heiguozhi.wang/tools/metronome.html) — 日常练习用的节拍工具，可带语音提示。
- [五度圈](https://heiguozhi.wang/tools/circle-of-fifths.html) — 一眼看清调性关系与常见和弦走向。
- [试音场](https://heiguozhi.wang/tools/tone-playground.html) — 拼效果器、箱头、箱体，在线试听电吉他/电贝司音色。
- [和弦字典](https://heiguozhi.wang/tools/chord-dictionary.html) — 吉他与尤克里里指法、构成音，可试听。
- [指板可视化](https://heiguozhi.wang/tools/fretboard.html) — 在吉他、贝斯、尤克里里指板上查看音阶与和弦。
- [音高频率参考](https://heiguozhi.wang/tools/pitch-frequency.html) — 可调 A4 的音名频率表，可试听。
- [音阶探索器](https://heiguozhi.wang/tools/scale-explorer.html) — 浏览 20+ 种音阶，带指板与试听。
- [和弦进行构建器](https://heiguozhi.wang/tools/progression-builder.html) — 按级数拼和弦进行，可调节 BPM 并播放。
- [鼓机](https://heiguozhi.wang/tools/rhythm-patterns.html) — 多种风格节奏型，可调速度。
- [音程听辨](https://heiguozhi.wang/tools/ear-training.html) — 练耳朵，听辨常见音程。
- [线规转换器](https://heiguozhi.wang/tools/wire-gauge-converter.html) — AWG、SWG、线径与截面积互算，方便布线选型。
