# เครื่องมือดนตรีออนไลน์

เว็บไซต์อ้างอิงสำหรับเครื่องมือฝึกซ้อม อุปกรณ์ช่วยเรียนทฤษฎีดนตรี และการค้นหาเลขซีเรียลกับรหัสวันที่อะไหล่ของอุปกรณ์ดนตรีหลายแบรนด์

เว็บไซต์: [https://heiguozhi.wang/th/](https://heiguozhi.wang/th/)

ภาษาอื่น: [English](./README.md) · [简体中文](./README.zh-Hans.md) · [繁體中文](./README.zh-Hant.md) · [日本語](./README.ja.md) · [한국어](./README.ko.md) · [Español](./README.es.md) · [Tiếng Việt](./README.vi.md) · [Bahasa Indonesia](./README.id.md) · [Português (Brasil)](./README.pt-BR.md)

## เครื่องมือ

- [เครื่องตั้งสาย](https://heiguozhi.wang/th/tools/tuner.html) — ตรวจจับความสูงเสียงแบบเรียลไทม์ผ่านไมโครโฟนสำหรับกีตาร์ เบส ไวโอลิน และเครื่องดนตรีอื่น รองรับการปรับค่า A4 อ้างอิงที่ใช้ร่วมกันทั้งเว็บไซต์ (392–470 Hz)
- [เมโทรนอม](https://heiguozhi.wang/th/tools/metronome.html) — เมโทรนอมออนไลน์พร้อมจังหวะ แท็ปเทมโป และสัญญาณเสียงพูดแบบเลือกได้ สำหรับฝึกซ้อมและการฝึกจังหวะ ภายในหน้ามีลิงก์ไปยังรุ่นเบาสำหรับนาฬิกา จอขนาดเล็ก และเบราว์เซอร์รุ่นเก่า
- [วงจรคู่ห้า](https://heiguozhi.wang/th/tools/circle-of-fifths.html) — วงจรคู่ห้าแบบอินเทอร์แอกทีฟครอบคลุมโหมดคริสตจักร ความสัมพันธ์ของคีย์ คีย์เมเจอร์/ไมเนอร์ที่สัมพันธ์กัน และการเคลื่อนไหวฮาร์โมนีที่พบบ่อย เหมาะกับการแต่งเพลง การเรียบเรียง และการเรียนทฤษฎี
- [สนามทดลองโทน](https://heiguozhi.wang/th/tools/tone-playground.html) — แซนด์บ็อกซ์สายสัญญาณสำหรับกีตาร์/เบสไฟฟ้า: เปดัล หัวแอมป์ IR คาบิเน็ต และ DI พร้อมการสลับเทียบ A/B ไบพาสทั้งสายสัญญาณ เปรียบเทียบคลื่นแห้ง/เปียก และลิงก์แชร์ชุดเสียง บางหัวรองรับโทน NAM และสามารถใช้ไมโครโฟนหรืออัปโหลดเสียงแห้งในเครื่องได้ เป็นการจำลองเชิงสอน—ไม่ใช่สินค้าทางการของแบรนด์ใด
- [ดิกชันนารีคอร์ด](https://heiguozhi.wang/th/tools/chord-dictionary.html) — อ้างอิงคอร์ดกีตาร์และอูคูเลเล่ (เมเจอร์ ไมเนอร์ เซเวนธ์ ซัสเพนเดด ฯลฯ) พร้อมรูปนิ้วเปิด/เลื่อนได้ แผนภาพ SVG รายการโน้ต และการเล่นเสียงตัวอย่าง
- [เฟรตบอร์ด](https://heiguozhi.wang/th/tools/fretboard.html) — เฟรตบอร์ดแบบอินเทอร์แอกทีฟสำหรับกีตาร์ เบส อูคูเลเล่ แมนโดลิน แบนโจ รวมถึงเครื่องสายดีดดั้งเดิม (เหลียวฉิน พิพา จงหลวน ต้าหลวน และเยว่ฉิน) รองรับการตั้งสายหลายแบบ เทมเพลตสเกล/คอร์ด มุมมอง 12 เฟรตหรือครบทุกเฟรต และการฟังเสียงตัวอย่าง
- [ความถี่](https://heiguozhi.wang/th/tools/pitch-frequency.html) — ตารางความถี่ตามระบบเทมเปอร์เมนต์เท่า 12 เสียง ปรับ A4 ได้ (392–470 Hz) แสดงความถี่เชิงทฤษฎีของทุกครึ่งเสียงตั้งแต่ C0 ถึง C10 พร้อมเล่นทีละโน้ต
- [ตัวสำรวจสเกล](https://heiguozhi.wang/th/tools/scale-explorer.html) — รายการสเกลมากกว่ายี่สิบแบบ (เมเจอร์ ไมเนอร์ เพนทาโทนิก บลูส์ สเกลสมมาตร และสเกลเอกซอติก) พร้อมการแสดงเฟรตบอร์ดหลายเครื่องดนตรี (12 เฟรตหรือครบทุกเฟรต) และการเล่นเสียง
- [คอร์ดโปรเกรสชัน](https://heiguozhi.wang/th/tools/progression-builder.html) — สร้างโปรเกรสชันจากระดับคอร์ด รองรับลำดับที่กำหนดเอง พรีเซ็ตทั่วไป การปรับ BPM และการเล่นเสียง
- [จังหวะ](https://heiguozhi.wang/th/tools/rhythm-patterns.html) — คลังรูปแบบกลองตามสไตล์ (ร็อก ฟังก์ ซัมบา เร็กเก้ ฯลฯ) พร้อมการปรับ BPM และการเล่นกลับแบบภาพ
- [ฝึกหู](https://heiguozhi.wang/th/tools/ear-training.html) — เครื่องมือฝึกแยกช่วงเสียงพร้อมชุดช่วงเสียงและระดับความยากหลายแบบ รองรับการนำเสนอแบบขึ้น ลง หรือเสียงประสาน และบันทึกอัตราถูกต้อง
- [ขนาดสายไฟ](https://heiguozhi.wang/th/tools/wire-gauge-converter.html) — แปลงค่าระหว่าง AWG, SWG, เส้นผ่านศูนย์กลางเมตริก/อิมพีเรียล และพื้นที่หน้าตัด สำหรับงานเดินสายเครื่องดนตรีและระบบเสียง

### รหัสวันที่อะไหล่

- [Celestion](https://heiguozhi.wang/th/sn-decoders/celestion.html) — ค้นหารหัสวันที่โรงงานและข้อมูลอ้างอิงปีที่ผลิตสำหรับลำโพงกีตาร์ (ไม่ใช่ระบบ EIA)
- [รหัสวันที่พอต](https://heiguozhi.wang/th/sn-decoders/pot.html) — ค้นหารหัสวันที่แบบ EIA ของสหรัฐสำหรับพอตกีตาร์และเบสไฟฟ้า (ผู้ผลิต ปี และสัปดาห์)
- [รหัสวันที่ EIA ลำโพง](https://heiguozhi.wang/th/sn-decoders/speaker-eia.html) — ค้นหารหัสวันที่แบบ EIA ของสหรัฐสำหรับลำโพงแอมป์กีตาร์ (Jensen, Rola, Oxford, Utah, Eminence และอื่น ๆ)
- [รหัสวันที่ EIA หม้อแปลง](https://heiguozhi.wang/th/sn-decoders/transformer-eia.html) — ค้นหารหัสวันที่แบบ EIA ของสหรัฐสำหรับหม้อแปลงและโช้กในแอมป์กีตาร์วินเทจ (Schumacher, Triad, Stancor และอื่น ๆ)

ผลลัพธ์เป็นการประมาณปีที่ผลิตและคุณสมบัติที่เกี่ยวข้อง (วันที่ของอะไหล่เป็นเพียงขอบล่างของวันผลิตตัวเครื่อง) ไม่ถือเป็นการรับรองความแท้หรือการประเมินมูลค่า
