# เครื่องมือดนตรีออนไลน์

เว็บฟรีสำหรับนักดนตรี: เครื่องมือฝึกซ้อมและทฤษฎีดนตรี พร้อมค้นหาเลขซีเรียลและปีที่ผลิตของเครื่องดนตรีหลายแบรนด์

เปิดเว็บไซต์: [https://heiguozhi.wang/th/](https://heiguozhi.wang/th/)

คู่มือนี้มีภาษาอื่น: [English](./README.md) · [简体中文](./README.zh-Hans.md) · [繁體中文](./README.zh-Hant.md) · [日本語](./README.ja.md) · [한국어](./README.ko.md) · [Español](./README.es.md) · [Tiếng Việt](./README.vi.md) · [Bahasa Indonesia](./README.id.md) · [Português (Brasil)](./README.pt-BR.md)

## เครื่องมือ

- [เครื่องตั้งสาย](https://heiguozhi.wang/th/tools/tuner.html) — ตั้งสายด้วยไมโครโฟน ใช้ได้กับเครื่องดนตรีหลายชนิด
- [เมโทรนอม](https://heiguozhi.wang/th/tools/metronome.html) — คลิกชัดเจนสำหรับฝึกซ้อม มีคิวเสียงได้
- [วงจรคู่ห้า](https://heiguozhi.wang/th/tools/circle-of-fifths.html) — ดูความสัมพันธ์ของคีย์และการเคลื่อนไหวฮาร์โมนีที่พบบ่อย
- [สนามทดลองโทน](https://heiguozhi.wang/th/tools/tone-playground.html) — จัดเปดัล แอมป์ คาบิเน็ต แล้วลองโทนกีตาร์/เบสออนไลน์
- [ดิกชันนารีคอร์ด](https://heiguozhi.wang/th/tools/chord-dictionary.html) — รูปนิ้วกีตาร์และอูคูเลเล่ โน้ตประกอบ และเสียงตัวอย่าง
- [เฟรตบอร์ด](https://heiguozhi.wang/th/tools/fretboard.html) — โน้ต สเกล และคอร์ดบนกีตาร์ เบส หรืออูคูเลเล่
- [ความถี่](https://heiguozhi.wang/th/tools/pitch-frequency.html) — ตารางความถี่ปรับ A4 ได้ พร้อมเล่นเสียง
- [ตัวสำรวจสเกล](https://heiguozhi.wang/th/tools/scale-explorer.html) — สเกล 20+ แบบบนเฟรตบอร์ดพร้อมเสียง
- [คอร์ดโปรเกรสชัน](https://heiguozhi.wang/th/tools/progression-builder.html) — สร้างและเล่นโปรเกรสชันตามดีกรี
- [จังหวะ](https://heiguozhi.wang/th/tools/rhythm-patterns.html) — แพตเทิร์นตามสไตล์ ปรับ BPM ได้
- [ฝึกหู](https://heiguozhi.wang/th/tools/ear-training.html) — ฝึกแยกช่วงเสียงด้วยหู
- [ขนาดสายไฟ](https://heiguozhi.wang/th/tools/wire-gauge-converter.html) — แปลง AWG / SWG / เส้นผ่านศูนย์กลาง / พื้นที่หน้าตัด สำหรับสายเสียง
